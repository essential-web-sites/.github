# Essential Web

Websites als Service für Unternehmen in Österreich. Design, Hosting und Betreuung sind inklusive.

Essential Web ist ein Angebot der Essential Code GmbH.

## Was du hier findest

Jede Website, die wir für Kundinnen und Kunden betreuen, hat ein eigenes Repository in dieser Organisation. Die Repositories enthalten den Quellcode der jeweiligen Website. Wer Inhalte bearbeitet, meldet sich mit GitHub über die Essential Web App an und arbeitet im Editor der eigenen Website. Du musst dafür keinen Code anfassen.
